# Eleven100 ERP v1.2.3

Security, HR ID-card and installer hardening release.

## Highlights

- HR ID-card path-traversal fix and authenticated upload proxy
- ID-card data integrity, validation, audit logging and clear upload errors
- Manual production now saves `employee_id`, employee photos and logos correctly
- ID-card rendering, QR/barcode visibility, PNG export and print fixes
- HR department/job-title data quality, required fields and onboarding assignment
- HR menu permission gating, keyboard-friendly dropdowns and mobile drawer fixes
- Installer CSRF, MariaDB database checks and optional `CREATE DATABASE`
- Schema patcher onboarding hash backfill and idempotent migration handling
- Final schema check: 140 entries, 0 errors

## Upgrade

1. Log in as an administrator.
2. Open **Settings → Maintenance → System Updates**.
3. Apply the update patch and enter the password + `APPLY`.
4. Run the Schema Patcher and confirm it completes with 0 errors.

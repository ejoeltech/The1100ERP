# Eleven100 ERP v1.2.9

Tools rebuild: safer AI design, a complete proposal workflow, and a defensible ROI model.

## System Designer

- Validates and normalizes planner/implementation requests before any AI call.
- Caps request bodies and returns clear 422/500 responses instead of rate-limit errors.
- Recomputes string VOC (with a 15% cold-temperature margin) and array current from the submitted panel specs; unsafe arrangements are flagged with explicit warnings.
- Scales battery-bank capacity by battery quantity.
- “Clear selection” resets every field the datasheet filled.
- Labels ISC and IMP correctly in panel options.
- PDF export tolerates malformed AI shapes and strips unsafe markup.

## Proposal Creator

- Sanitizes AI and editor HTML through a shared allow-list before storage and rendering.
- Validates and caps proposal saves; reports errors consistently.
- Adds draft list/load endpoints and a “Resume a saved draft” control.
- Persists customer names and carries them into converted quotes.
- Locks proposals during conversion; repeated clicks return the same quote instead of duplicating it.
- Keeps converted proposals read-only and links them to their quote.

## ROI Calculator

- Replaces the 100% displacement assumption with a configurable solar-offset input.
- Handles unrecoverable payback without a misleading number.
- Validates inputs, rate-limits and caches the AI narrative, and returns figures even when the AI is unavailable.
- Cleans Markdown from the narrative and adds a “Use in Proposal” handoff.

## Navigation

- Tools is grouped into **Design & Propose** and **Data** on desktop and mobile.
- Datasheet Catalog now lives once under Tools → Data with correct active states.
- Proposal Creator is permission-gated to document/quote creation.

Apply through **Settings → Maintenance → System Updates**, or use **About → Check for updates** with the v1.2.6+ updater. A current backup and the admin password + `APPLY` confirmation are required.

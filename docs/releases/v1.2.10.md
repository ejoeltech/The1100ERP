# Eleven100 ERP v1.2.10

AI branding fix: generated proposals and AI copy now use the operator's configured company name.

## Fix

- Added a shared `erpCompanyName()` helper that reads **Settings → Company Name**, ignores the app default, and only falls back to the application name when no company is configured.
- Proposal Creator AI now brands every proposal with the configured company name, address, phone, email and website.
- ROI Calculator, ERP Assistant, product descriptions and spec recommendations now use the configured company name instead of hardcoded Eleven100/1100ERP or generic wording.
- Prompts explicitly forbid the model from calling the company Eleven100 ERP, 1100ERP, or any other application/default name.

## Assets

- `1100erp-v1.2.10-update.zip`
- `1100erp-v1.2.10-update.zip.sha256`

## Upgrade

Apply through **Settings → Maintenance → System Updates**, or use **About → Check for updates** with the v1.2.6+ updater. A current backup and the admin password + `APPLY` confirmation are required.

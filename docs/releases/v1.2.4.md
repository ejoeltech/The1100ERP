# Eleven100 ERP v1.2.4

Hotfix for the desktop navigation dropdowns.

## Fix

- Removed the horizontal-scroll rule that clipped absolutely positioned dropdown panels.
- Restored normal hover and click behaviour for Store, Inventory, Documents, Tools, HR, Admin and the user menu.

## Asset

`1100erp-v1.2.4-hotfix.zip` contains `includes/header.php` and `includes/version.php` plus `update_script.php`.

## Upgrade

1. Log in as an administrator.
2. Open **Settings → Maintenance → System Updates**.
3. Apply the hotfix patch and enter the password + `APPLY`.
4. Run the Schema Patcher if prompted.

# Eleven100 ERP v1.2.5

GitHub-based update manager for super admins and developer admins.

## Added

- **Check for updates** on the About page.
- **Download update** direct link to the matching GitHub release asset.
- **Update now** downloads, verifies and applies the latest update ZIP without a manual upload.
- **Rollback last update** restores the files saved before the last applied update.

## Security controls

- Update actions are limited to super admins and developer admins.
- Requires the current admin password and typed `APPLY` / `ROLLBACK`.
- Requires confirmation that a current backup exists.
- Every applied update automatically creates a file backup under `storage/updates/`.
- Downloaded assets must come from GitHub-owned HTTPS hosts.
- Every release ZIP must have a matching `.sha256` asset; the checksum is verified before extraction.
- ZIP inspection still blocks traversal, symlinks, `.env*`, `.user.ini` and forbidden config files.
- Failed extraction/update runs automatically restore the previous files.
- Rollback restores files only; database schema changes are additive and are not reversed.

## Asset

`1100erp-v1.2.5-update.zip` plus `1100erp-v1.2.5-update.zip.sha256`

## Upgrade

1. Log in as a super admin or developer admin.
2. Open **About**.
3. Click **Check for updates**.
4. Click **Download update** to save the ZIP, or **Update now** to apply it directly.
5. Confirm the backup checkbox, enter the admin password and type `APPLY`.
6. If anything fails, use **Rollback last update** with `ROLLBACK`.

# Eleven100 ERP v1.2.7

Logo upload stability fix.

## Fix

- Logo uploads no longer fail with a bare HTTP 500 on large images.
- Image dimensions are checked before GD allocates memory.
- Images over 6000 px per side or 24 megapixels are rejected with a normal error message.
- The favicon is created from the resized image instead of decoding the logo a second time.
- Upload failures and save failures are returned as redirects with a readable message.
- Absolute include paths remove dependence on the server working directory.

## Assets

- `1100erp-v1.2.7-update.zip`
- `1100erp-v1.2.7-update.zip.sha256`

## Upgrade

Apply through **Settings → Maintenance → System Updates**, then retry the logo upload.

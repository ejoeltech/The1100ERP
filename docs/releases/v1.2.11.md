# Eleven100 ERP v1.2.11

Update packaging fix and AI company branding.

## Fix

- Rebuilt the update package with forward-slash ZIP entries. The v1.2.10 package was built on Windows and stored paths with backslashes, so Linux extracted files such as `includes\version.php` as literal filenames and the application stayed on the previous version.
- The update script now removes stray files and directories whose names contain a literal backslash, cleaning up any leftovers from the broken package.
- Added `deploy/build-update-package.php`, which builds update ZIPs with portable `/` paths and writes the matching SHA-256 file.
- AI proposals, ROI analysis, ERP Assistant, product descriptions and spec recommendations now use the configured company name from Settings, not Eleven100 ERP or 1100ERP.
- Proposal prompts include the configured company address, phone, email and website.

## Assets

- `1100erp-v1.2.11-update.zip`
- `1100erp-v1.2.11-update.zip.sha256`

## Upgrade

Apply through **Settings → Maintenance → System Updates**, or use **About → Check for updates**. A current backup and the admin password + `APPLY` confirmation are required.

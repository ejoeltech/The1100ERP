# Eleven100 ERP v1.2.8

Reorganized navigation with permission-aware grouping.

## Navigation

- Added a **Sales** menu for Customers and Leads.
- Merged Store into **Inventory**:
  - Catalog: Products, Datasheet Catalog
  - Stock: Store Items, Categories, Accessories
- Grouped **Documents** into Sales Documents, Finance and Records.
- Grouped **HR** into Overview, Time & Attendance, People Operations, ID Cards, Onboarding, Payroll and Recruitment.
- Grouped **Admin** into Access and System.
- Attendance and Leave are now visible to all signed-in users as self-service links.
- Menu items are permission-gated to the same keys their target pages require.
- Developer admins with the relevant permissions now see the Admin menu.
- Desktop menu groups receive active states based on the current page.

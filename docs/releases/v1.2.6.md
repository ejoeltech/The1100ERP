# Eleven100 ERP v1.2.6

Private-repository support for the GitHub update manager.

## Fix

- v1.2.5 was published before the private-repository path was completed. GitHub API and asset requests now support an optional read-only `GITHUB_TOKEN`.
- Added a server-side **Download update** endpoint that verifies SHA-256 and streams the ZIP, so private release assets are not exposed as direct browser URLs.
- The About page download button now uses that endpoint.
- `GITHUB_TOKEN` / `GH_TOKEN` can be set in `.env`; a read-only token with access to the private repository is required.
- Public repositories continue to work without a token.

## Update manager

- Update actions are limited to super admins and developer admins.
- Requires the admin password and typed `APPLY` / `ROLLBACK`.
- Requires confirmation that a current backup exists.
- Every update creates an automatic file backup under `storage/updates/`.
- Every update ZIP must have a matching `.sha256` asset; checksums are verified before extraction.
- Failed applies automatically restore the previous files.
- **Rollback last update** restores files; database schema changes remain additive.

## Assets

- `1100erp-v1.2.6-update.zip`
- `1100erp-v1.2.6-update.zip.sha256`

## Upgrade

Apply this release through the existing manual **Settings → Maintenance → System Updates** upload flow. After it is installed, later releases can use **About → Check for updates → Update now**.

# Eleven100 ERP v1.2.12

Document export parity: HTML and JPEG now use the same A4 document as the PDF.

## Fix

- HTML export now renders the PDF template with real A4 geometry (210 mm page, 180 mm content, 15 mm margins), so proportions and line breaks match the PDF.
- Logos and signatures are inlined as data URIs, so they appear in HTML and JPEG exports instead of resolving to a filesystem path.
- Quote HTML export now includes the creator's signature and the same Terms & Conditions and Warranty pages as the PDF.
- JPEG export now rasterises the actual PDF when Imagick, Ghostscript, pdftoppm or ImageMagick is available, so the image is a true render of the PDF.
- When no server rasteriser is available, JPEG is rendered in the browser from the identical A4 HTML with html2canvas, then padded to an exact A4 aspect ratio. The old hand-drawn GD renderer (duplicated quantities, clipped content, missing logo) has been removed.
- Invoice view now exposes the same JPEG and HTML export buttons as quotes and receipts.
- Added a document-export regression test covering quote, invoice and receipt PDFs plus the browser HTML contract.
